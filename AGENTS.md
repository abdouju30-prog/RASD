# Homologa — agent notes

## Cursor Cloud specific instructions

- Do not record or generate demo videos or screen recordings.
- For UI verification, use screenshots only (or curl / HTML when a browser is unavailable).
- `/no-test` skips testing entirely.

## Do not strip existing information

Matter sheets, product sheets and the control tower already carry operational facts: usages, crops, pests, dose, DAR, regulatory status, products, suppliers.

Do not remove, hide, or “simplify away” that information unless the user explicitly asks to drop a named block **and then confirms**. Silence, a missing reply, or a request that only adds a feature is not confirmation. When in doubt, add beside what is there — never replace a table of usages by a count.
